# petlog-legal

Public privacy and support pages for apps published by Liao Yilin.

[Product directory and support](https://roik378.github.io/petlog-legal/)

The directory covers the existing LittleMoni, PetCare Proof, PetLog, PetMotion,
Read Water, and TimeTox documents. The original document filenames and wording
are retained; `support.css` supplies shared system-font typography and navigation.
App-icon thumbnails are derived from the existing Yi Studio catalog assets.

Run the dependency-free checks with `python3 -B -m unittest discover -s tests -v`.
The preservation checks compare all original documents against commit
`d23209f0a5add2e2ad5908ee9e99e8f0af186e3c`.
